# Soft Warm Shaders

Мягкие тёплые шейдеры для Minecraft (Iris / OptiFine), рассчитанные на очень слабые ПК. Всё освещение считается за один проход, без deferred-буферов, без SSAO и отражений.

## Что есть

- **Небо**: градиент для дня, заката и ночи, тёплое свечение солнца, холодное свечение луны, мягкие звёзды, облака подкрашиваются под время суток.
- **Тени от блоков**: мягкие, 5 выборок. Днём их отбрасывает солнце, ночью луна. Тень плавно затухает на закате, поэтому при смене солнца на луну картинка не дёргается.
- **Свет**: тёплый свет солнца и факелов, холодные приподнятые тени, мягкое полуламбертовское освещение граней.
- **Лучи света**: 8 выборок глубины, сильнее на рассвете и закате.
- **Туман** в цвет неба, отдельный туман под водой.
- Тёплая цветокоррекция, мягкий тонмап, лёгкая виньетка.

## Установка

1. Скачай [`shaders2.zip`](https://github.com/mardeltygd-ui/shaders2/raw/main/shaders2.zip).
2. Положи его (не распаковывая) в папку `shaderpacks` внутри папки Minecraft.
3. В игре: Настройки → Шейдеры → выбери `shaders2.zip`.

Если собираешь сам: в архиве папка `shaders` должна лежать в корне (кнопка GitHub «Download ZIP» добавляет лишнюю папку сверху, она не подойдёт). Скрипт `make_zip.sh` собирает правильный архив.

## Если всё равно лагает

В настройках шейдера (все опции есть в меню и переведены):

| Что сделать | Эффект |
|---|---|
| Разрешение теней 512 или 768 | самый большой выигрыш |
| Дальность теней 32 | меньше геометрии в теневом проходе |
| Мягкость теней 0 | одна выборка вместо пяти |
| Лучи света выкл. или качество 4 | убирает проход с лучами |
| Тени выкл. | теневой проход становится бесплатным |

## Структура

```
shaders/
  lib/settings.glsl   все опции
  lib/common.glsl     небо, цвета света и ambient (общий код)
  lib/lit.vsh/.fsh    освещение и тени для блоков, сущностей, руки
  gbuffers_*          обёртки над lit + небо, облака, погода
  shadow.*            теневая карта
  composite.*         лучи света, тонмап, цветокоррекция
```

Протестировано только на компиляцию GLSL. Если на каком-то железе что-то выглядит не так, напиши, какие значения подправить.
