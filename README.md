# Soft Warm Shaders

Мягкие тёплые шейдеры для Minecraft (Iris / OptiFine), рассчитанные на очень слабые ПК. Всё освещение считается за один проход, без deferred-буферов, без SSAO и отражений.

## Что есть

- **Небо**: градиент для дня, заката и ночи, тёплое свечение солнца, холодное свечение луны, мягкие звёзды, облака подкрашиваются под время суток.
- **Тени от блоков**: мягкие. Днём их отбрасывает солнце, ночью луна. Тень плавно затухает на закате, поэтому при смене солнца на луну картинка не дёргается.
- **Свет**: тёплый свет солнца и факелов, холодные приподнятые тени, мягкое полуламбертовское освещение граней.
- **Туман** в цвет неба, отдельный туман под водой.
- Тёплая цветокоррекция и мягкий тонмап, всё считается прямо в шейдерах блоков, без дополнительных проходов.

## Установка

Положи zip (не распаковывая) в папку `shaderpacks` внутри папки Minecraft и выбери его в Настройки → Шейдеры.

| Файл | Для кого |
|---|---|
| [`shaders2.zip`](https://github.com/mardeltygd-ui/shaders2/raw/main/shaders2.zip) | обычная версия: маленькие мягкие тени (512, дальность 24) |
| [`shaders2-lite.zip`](https://github.com/mardeltygd-ui/shaders2/raw/main/shaders2-lite.zip) | для самых слабых ПК: без теней, только небо, свет и туман |

Кнопка GitHub «Download ZIP» не подойдёт: она добавляет лишнюю папку сверху. Бери готовые zip по ссылкам выше.

## Если лагает или вылетает

Сначала попробуй `shaders2-lite.zip`. В настройках шейдера:

| Что сделать | Эффект |
|---|---|
| Разрешение теней 128–256 | самый большой выигрыш |
| Дальность теней 16 | меньше геометрии в теневом проходе |
| Мягкость теней 0 | одна выборка вместо пяти |
| Тени выкл. | теневой проход становится бесплатным |

## Структура

```
src/                  исходники
  lib/settings.glsl   все опции
  lib/common.glsl     небо, цвета света и ambient (общий код)
  lib/lit.vsh/.fsh    освещение и тени для блоков, сущностей, руки
  gbuffers_*          обёртки над lit + небо, облака, погода
  shadow.*            теневая карта
build.py              собирает zip: раскрывает #include и делает обычную и lite-версии
```

Протестировано только на компиляцию GLSL. Если на каком-то железе что-то выглядит не так, напиши, какие значения подправить.
